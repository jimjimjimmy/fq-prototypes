## What This Is

A shared research project that captures recorded UX feedback sessions from Mike Whitmire (CEO & Co-founder). Each session is transcribed, structured into themes and priority issues, and stored in `knowledge/` for reference by the product and design team. A prototype is included for testing proposed solutions against Mike's feedback.
