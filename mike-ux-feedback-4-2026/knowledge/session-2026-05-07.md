## Feedback by Theme

### Layout & Space
- Top section is too large — consumes too much vertical space, leaving the bottom section feeling pointless
- Needs a collapsing mechanism for the top panel, especially once in "review transaction mode"
- Requested an **"uber collapse"** button — a single toggle that hides everything non-essential so users can focus on the core table, then expand back
- "Imagine if you could just run these headers all the way to the top of the screen right here, you got everything"

### Navigation & Findability
- A key feature (daily rec) is too hard to find — "Kind of tough to find, I'm surprised I realized that"
- Should be accessible via a filter or from within Controls — "maybe under controls or something"
- Suggested renaming the Search view to the actual thing it does (e.g., "Journal Entries"), then adding a visible filter — "why call it search? Just name it the thing"
- Proposed restructuring: **Dashboard = overview**, **Journal/Search = working list**

### Missing Feature: Text Search
- No text search — called out as a significant gap
- "That's brutal. Like, makes it pretty unusual compared to Excel. Not great."
- "How do we get text search in here?" — clear P0-level ask

### Table Design & Data Alignment
- Numbers should be **right-aligned**, text should be **left-aligned** — not consistently applied
- Font size could be slightly smaller
- Alignment inconsistency across headers, totals, and indented rows felt "standard or not"
- Middle-aligned header noted positively when corrected: "Now we're talking"
- "The numbers right aligned. I think these should be right aligned also."

### Notes Column
- Notes appearance: "notes look like trash"
- Center-aligned note content preferred
- Open question: "Do people actually use this?" — possible signal to evaluate feature value

### Complexity
- "We need this whole thing to be simpler than this"
- Suggested cutting complexity and showing a more basic table view: "Let's just get rid of this"
- "How big do we expect this page to realistically get?" — scalability of the layout questioned

### User Profile (New Idea)
- Clicking a user's name/avatar should open a profile page showing:
  - Join date
  - Number of sign-offs
  - Review notes submitted
  - Journal entries posted

### Terminology
- "Reoccurring" vs "recurring" flagged: "I always get weirded out when I see reoccurring" — noted there's been prior debate
