# Case Study: Scheduler 1 Many

**Status:** exploration  
**Jira:** https://floqast.atlassian.net/browse/IDEA-2576

---

## Problem

Post-MVP exploration of FloQast's Scheduler concept where a single schedule orchestrates many tasks. Scheduler graduates out of Admin Settings into its own first-class module with dedicated left nav placement.

---

## Goal

Demonstrate the 1:Many model - a Schedule containing multiple ordered Tasks - and explore the UX implications of creation flow, task dependencies, run history, and failure handling.
