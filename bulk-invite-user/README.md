# Bulk Invite User

> Let admins create multiple users at once instead of one at a time.

## What This Is

A prototype for a bulk user creation flow inside Admin Settings → Team Members.
Today admins set up new users one at a time; this explores letting them input
details for many users simultaneously. The goal is to cut the repetitive manual
data entry that slows setup for large-userbase customers and to make the admin
experience faster and less tedious.
