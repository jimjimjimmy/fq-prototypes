# Recs Translation for Workday

> Exploring how currency translation works in FloQast Reconciliations for Workday ERP accounts.

## What This Is

A static HTML prototype showing the Reconciliations table with currency translation support. It demonstrates how financial values (Per GL, Rec. Balance, Difference) display translated amounts alongside functional currency, including exchange rate popovers, error states, and side drawer currency settings for individual and grouped accounts.
