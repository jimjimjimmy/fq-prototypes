# Agents & Playbooks

> Fully functional prototype for FloQast's Agents and Playbooks product — Agent Library + AutoBuild creation flow.

## What This Is

A React + Flow UI prototype built against the Figma designs in the AI-Native FloQast file.
Covers the Agent Library (folder navigation, playbook cards, empty states) and the complete
Agent creation flow (AutoBuild chat interface with inline clarifying questions, file upload,
and a live Playbook document split-view).
