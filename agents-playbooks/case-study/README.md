## Problem

Fully functional prototype for FloQast's Agents and Playbooks product. Covers Agent Library, the AutoBuild chat creation flow, Playbook Viewer, and live cross-prototype integration with COSO AI RCM.

## Goal

Demonstrate the end-to-end lifecycle of an AI agent - from creation and COSO-compliant testing through approval, go-live, and automatic registration in the compliance manager's risk control matrix.
