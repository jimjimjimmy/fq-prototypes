# Transform Extract

> PDF extraction template builder — the UX for FloQast's Extract feature

## What This Is

A prototype + design exploration for FloQast's document extraction flow. Users upload a zip of PDFs, pick or build a template that defines what to extract, process the batch, validate per-document, and approve. The prototype focuses on the template-builder modal, the values-vs-editor mode split, and the AI chat experience for conversational template editing.
