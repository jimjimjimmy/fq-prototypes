# Case Study: Transform Extract

**Status:** prototyping  
**Jira:** _Not tracked._

## Problem

PDF extraction experience for FloQast - users upload source documents, pick or build an extraction template, process the batch, validate extracted values, and approve. Explores template-builder UX, values vs editor modes, and an AI chat bar for conversational template modification.

---

## Goal

Define a scalable UX for AI-assisted document extraction covering the full lifecycle: template creation, processing, validation, approval, and mid-flow edge cases.
