# Setup Guide

Daily development reference for working with Catalyst.

## Prerequisites

- **Node.js** 18.0+ (20.x recommended)
- **npm** 9+ (or pnpm 8+)
- A modern browser (Chrome, Firefox, Safari, Edge)

## Installation

```bash
# Clone the repository
git clone https://github.com/benjaminell_floqast/Catalyst.git
cd Catalyst

# Install dependencies
npm install

# Start the development server
npm run dev
```

Vite will start at `http://localhost:5173` with hot module replacement.

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start Vite dev server with HMR |
| `npm run build` | Type-check with `tsc` then build for production |
| `npm run preview` | Preview the production build locally |

## Common Tasks

### Add a New Custom Component

1. Create `src/components/MyComponent.tsx`
2. Export a named function component
3. Import it in the parent component (usually `App.tsx` or a page component)
4. For icons, import from `lucide-react`
5. For animations, import from `motion/react`

### Modify Mock Data

Task data lives directly in `src/components/TaskManagement.tsx` (the `tasks` array starting at line 49). Workflow data is in `src/components/WorkflowManagement.tsx` (the `workflowData` array starting at line 24).

To change the "current date" for overdue calculations, update `TaskManagement.tsx:27`:
```typescript
const today = new Date(2026, 1, 25); // Feb 25, 2026
```

### Add a New Page

Navigation is currently state-driven (no router). React Router integration is planned — see [plan.md](./plan.md), M1 issues 4–5.

1. Create a page component in `src/components/`
2. Import it in `src/App.tsx`
3. Add a new conditional render:
   ```typescript
   {currentPage === 'NewPage' && <NewPage />}
   ```
4. Add a navigation item in `src/components/Sidebar.tsx`

### Add a shadcn/ui Component

The project includes 48 shadcn/ui components in `src/components/ui/`. If you need one that's already there, just import it. For new components:

1. Visit [ui.shadcn.com](https://ui.shadcn.com)
2. Copy the component source into `src/components/ui/`
3. Ensure it imports `cn` from `./utils`
4. Install any new Radix dependencies: `npm install @radix-ui/react-[name]`

## Troubleshooting

### Tailwind classes not applying

Ensure `src/styles/globals.css` has `@import "tailwindcss";` as its first line. Tailwind v4 uses CSS-based configuration — no `tailwind.config.js` file is needed.

### Module not found errors

If an import can't be resolved:
1. Check if the file was moved during migration (paths should be relative to `src/`)
2. For `@/` imports, verify the `paths` alias in `tsconfig.json` points to `./src/*`
3. For Radix/library imports, check that versioned suffixes were stripped (e.g., `@1.1.2`)

### Hot reload not working

Vite HMR sometimes loses track of deeply nested imports. Try:
1. Save the file again
2. If that doesn't work, restart the dev server (`Ctrl+C` then `npm run dev`)

### TypeScript errors on build

The codebase was generated by Figma Make and may have loose typing. The `tsconfig.json` intentionally relaxes `noUnusedLocals` and `noUnusedParameters`. If you see errors from `tsc -b` during `npm run build`, either fix the types or add `// @ts-ignore` comments for Figma-generated code you don't plan to modify.
