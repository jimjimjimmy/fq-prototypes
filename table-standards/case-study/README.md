# Case Study: Table Standards

**Status:** prototyping  
**Jira:** _Not tracked._

---

## Problem

Design standardization effort to bring consistent interaction patterns to tables across FloQast. Defines filtering, saved views, column management, status chrome, density, and numerics across a profile ladder (P0 Simple through P3 complex) on AG Grid Enterprise.

---

## Goal

Define and prototype table interaction standards so every FloQast table uses the same design language - then hand engineering a clear target to harden in production.
