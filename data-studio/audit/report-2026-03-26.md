## Deferred Views — Next Audit Scope

These views are accessible from the tab bar and model rows but were not in scope for the initial audit. Each needs its own `/design-audit` pass.

### Connections view (`/data-studio/connections`) — Priority: High

**Why high:** Visible from the primary tab bar — any user switching tabs sees this immediately.

Key items spotted in scan:
| Item | What it is | Likely classification |
|---|---|---|
| Connections table | Custom div-based grid, not AG Grid | Yellow — needs AG Grid migration |
| Search input | Custom `<input>` + hand-rolled SVG | Green — swap to `Input isSearchable` |
| "Add Connector" button | Hardcoded `#186749` bg, custom `<button>` | Green — swap to FlowUI `Button` |
| Status badges | Local `StatusBadge` component in `connections/Badges.tsx` (NOT FlowUI) | Green — swap to FlowUI `StatusBadge` |
| Source badges | Custom `SourceBadge` (QBO, SFTP icons) | Red — keep, domain-specific |
| Error banner | Custom `ErrorBanner` | Red — keep, no FlowUI equivalent |
| 3-dot action menu | Hand-rolled popover with `useRef` + `mousedown` | Yellow — swap to FlowUI `DropdownButton` + `DropdownPanel` |
| Entity tags | Custom `<span>` chips | Green — swap to FlowUI `StatusBadge` or keep (low priority) |

Estimated effort: **M**
