4. AI Interaction Model Exploration

Directed Inline

Concept: AI pre-fills mapping suggestions in the field mapping grid. User reviews each row, accepts/rejects/modifies inline.

  • Built: Placeholder with mode label (toggled via DevToolbar)
  • To explore: Confidence indicators per suggestion, batch accept/reject, inline transformation editor
  • Strengths: Keeps user in context, visible progress, easy to audit
  • Risks: May feel tedious for large schemas, hard to express complex transformations

Conversational Chat

Concept: AI Chat panel for natural language instructions ("Map all date fields to ISO format", "Concatenate first and last name").

  • Built: Placeholder with mode label (toggled via DevToolbar)
  • To explore: Chat panel layout (floating vs side panel), mapping preview before apply, undo/history
  • Strengths: Powerful for bulk operations, natural for complex transformations
  • Risks: Less visible progress, harder to audit, may over-promise capability
