## Background

The Mapping page allows users to map their source system fields to FloQast's standard data model. Currently, field names appear without any contextual description, which requires users to consult external documentation to understand what each field means or expects.

## Problem

Users mapping their data — often during onboarding or integration setup — lack in-context guidance on what each standard model field represents. This creates friction, increases support volume, and raises the risk of mismatched mappings.

## Goal

Add a tooltip to each standard model field on the Mapping page that surfaces the field's description inline, so users can understand the field's purpose without leaving the page.

## User Story

As an onboarding customer or integration admin mapping source fields to FloQast's standard model, I want to see a brief description of each destination field so I can confidently map the correct source field to it.

## Requirements

* **R1 — Tooltip trigger:** Each field name in the standard model column of the Mapping page displays a tooltip icon (e.g., an info ⓘ icon). On hover (desktop) or tap (mobile), the tooltip appears.

* **R2 — Tooltip content:** The tooltip displays the field description as defined in FloQast's standard data model (source of truth: Data Model Revisions Jan 2026, "Field description" column).

* **R3 — Scope:** Tooltips apply to all fields across all models surfaced on the Mapping page: Accounts, Balances, GL Transactions, Subledger Transactions, Companies, Currencies, FX Rates, and Bank.

* **R4 — Source of truth:** Descriptions must be kept in sync with the data model definition sheet. Engineering should pull from a single source of truth — not hardcode strings — so updates to the model are reflected automatically or with a single update.

* **R5 — Accessibility:** Tooltips must be keyboard-accessible and meet WCAG 2.1 AA contrast requirements.

## Field Definitions by Model

### Accounts

| Field | Description |
| --- | --- |
| Account Name | Name of the general ledger account; the human-readable name for the account. |
| Account Number | General ledger account number; the common identifier for an account. |
| Account Id | Uniquely identifies the specific account record from its source system; allows FloQast to trace the source of the data. |
| Account Currency | The functional currency for the account; can be defined at the account level in the source system or inherited from the company. |
| Account Type | Indicates what type of account it is: asset, liability, equity, expense, or revenue. |
| Account Sub Type | Provides a more detailed categorization of the GL account. |
| Account Balance Type | Indicates the natural balance of an account: debit, credit, or does not apply. |
| Financial Statement | Indicates whether the account is a balance sheet or income statement account. |
| Exchange Rate Type | Indicates what type of exchange rate applies to transactions in this account: current, average, historic, or custom. |
| Active | Indicates whether the account is active in the source system; tells FloQast whether to expect additional data for the account. |
| Intercompany Identifier | Indicates whether the account is involved in intercompany activity. |
| Entity Association / Data Domain | Establishes a link between the account and the entity. |

### Balances

| Field | Description |
| --- | --- |
| Amount | Sum of transactions in the account for the period; represented as the ending balance in a trial balance report. |
| Balance Period | Period to which the balance applies. |
| Balance Date | Date to which the balance applies. |
| Trial Balance Type | Indicates whether the trial balance is consolidated, company, or dimensional. |
| Currency | Currency code in which the balance amount is denominated. |
| Link to Accounts | Foreign key linking the balance to the corresponding account record. |
| Dimensions | Dimensions provided in the trial balance report by which balances are broken out; required when trial balance type is dimensional. |
| Entity Association / Data Domain | Establishes a link between the balance and the entity. |

### GL Transactions

| Field | Description |
| --- | --- |
| Source Transaction Id | Uniquely identifies the specific transaction record from its source system; allows FloQast to trace the source of the data. |
| Transaction Date | Date on which the transaction occurred. |
| Posting Date | Date on which the transaction is posted in the accounting system; often the same as the transaction date but can differ. |
| Description | Description or memo of the transaction. |
| Transaction Amount (Local) | Amount of the transaction in the transaction currency. |
| Transaction Amount (Functional) | Amount of the transaction in the functional currency; allows aggregation across currencies. |
| Transaction Currency (Local) | Currency in which the transaction took place. |
| Transaction Currency (Functional) | Functional currency of the account or company; used to convert the transaction amount. |
| FX Rate | Exchange rate used to convert the transaction amount to the functional amount. |
| Account Identifier | Links the transaction to the corresponding account; foreign key to the Accounts model. |
| Transaction Type | Describes the type of transaction (e.g., journal entry, invoice, purchase order). |
| Posted | Indicates whether the transaction has been posted. |
| Vendor | Company or individual from whom goods or services were purchased; required for amortization. |
| Department | Internal organizational unit used to segment transactions and reporting; required for amortization. |
| Invoice Date | Date on which an invoice was issued; required for amortization. |
| Invoice Number | Sequential invoice number; required for amortization. |
| Asset ID | Identifier for the specific asset; required for amortization. |
| Expense GL Account | GL account number and name for the offsetting expense account; required for amortization. |
| Amortization Start Date | Date on which the amortization calculation begins. |
| Amortization End Date | Date on which the amortization calculation ends. |
| Amortization Useful Life | Number of months representing the useful life of the transaction. |
| Entity Association / Data Domain | Establishes a link between the transaction and the entity. |

### Subledger Transactions

| Field | Description |
| --- | --- |
| Transaction Id | Uniquely identifies the specific transaction record from its source system. |
| Transaction Date | Date on which the transaction occurred. |
| Posting Date | Date on which the transaction is posted in the accounting system. |
| Description | Description or memo of the transaction. |
| Local Amount | Amount of the transaction in the local currency. |
| Functional Amount | Amount of the transaction in the functional currency. |
| Local Currency | Currency in which the transaction took place. |
| Functional Currency | Functional currency of the account or company. |
| Account Type | Indicates the type of subledger account (e.g., Accounts Receivable, Accounts Payable, Fixed Assets). |
| Entity Association / Data Domain | Establishes a link between the subledger transaction and the entity. |

### Companies

| Field | Description |
| --- | --- |
| Source Id | Unique identifier for the company from the source system; allows FloQast to trace the company to its origin. |
| Company Name | Display name (human-readable) for the company. |
| Active | Indicates whether the company is currently active. |
| Country | Country where the company is based. |
| Legal Name | Full legal name of the company. |
| Local Currency | Local currency used by the company. |
| Functional Currency | Functional currency used by the company. |
| Reporting Currency | Reporting currency used by the company. |
| State / Province | State or province where the company is based. |
| Entity Association | Indicates which FloQast entities this company is associated with. |
| Company Relationships | Allows for establishing hierarchies between companies. |

### Currencies

| Field | Description |
| --- | --- |
| ISO Currency Code | Three-letter currency code that uniquely identifies the currency (e.g., USD, JPY, GBP). |
| Currency Name | Human-readable description of the currency. |
| Currency Symbol | Symbol used to display the currency; may contain special characters. |
| Active | Indicates whether the currency is active. |
| Precision | Number of digits past the decimal that the currency supports (e.g., 2 for USD, 0 for JPY). |

### FX Rates

| Field | Description |
| --- | --- |
| Rate ID | Unique identifier for the specific FX rate record. |
| Source Currency | Currency being converted from; foreign key to the Currencies model. |
| Target Currency | Currency being converted to; foreign key to the Currencies model. |
| Rate Type | Type of exchange rate: current, average, historic, or custom. |
| Rate Value | Exchange rate value; multiply the source currency amount by this to get the target amount. |
| Inverse Rate Value | Inverse of the rate value; multiply the target currency amount by this to get the source amount. |
| Effective Date | Date and time when the rate becomes effective. |
| End Date | Date and time when the rate is no longer effective; nullable. |
| Rate Name | Name of the exchange rate from the customer's source system. |

## Out of Scope

* Editing field descriptions from within the UI

* Tooltips on customer source fields (left-hand side of the mapping)

* Tooltip support for custom/non-standard fields

## Acceptance Criteria

* Every standard model field on the Mapping page has a tooltip icon

* Hovering or tapping the icon displays the correct field description per the data model definition

* Tooltips render correctly across Accounts, Balances, GL Transactions, Subledger Transactions, Companies, Currencies, FX Rates, and Bank models

* Tooltip copy matches the "Field description" column in the Data Model Revisions Jan 2026 sheet

* Tooltips are keyboard-navigable and pass WCAG 2.1 AA contrast
