Model Creation — 4 of 4: Versioning & Lifecycle (DRAFT)
Last modified: 2026-04-01 (updated by Alex Kearns)

This sub-PRD covers the lifecycle of a Model after it has been published: how users create and manage new versions when mappings need to change, how draft versions are discarded, how historical versions are archived, and how users monitor pipeline execution.

Key stories: V1-LC through V12-LC covering manual/auto draft creation, draft discard, pipeline logs, data preview, publish with Effective Date, autosave, version history, archiving, and archived version viewing.

Scenario B (past Effective Date re-publish with tear-down-and-rehydrate) is defined here. Scenario C (initial backfill) is in Sub-PRD 3.
