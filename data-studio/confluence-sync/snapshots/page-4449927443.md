## Why this changed

* **Terminology:** "Transform" is a separate FloQast product. Per [DATA-4115](https://floqast.atlassian.net/browse/DATA-4115) (deployed 2026-05-14), Data Studio uses "Mapping" / "Mapping Rule" instead. The new PRD's title and body have been audited accordingly.

* **Split into 2a + 2b:** The original PRD covered both the visual refresh of the field mapping grid (PRD 2a, target 6/30) AND the mapping logic layer with AI authoring (PRD 2b, target 9/30). These now live in separate documents to allow PRD 2a to ship first.

* **Q3 scope refinement (2026-05-18 / 2026-05-19):** A cross-check session against real customer SQL produced concrete scope expansions and resolved most of the prior open questions and gaps. See the new PRD for the full list.
