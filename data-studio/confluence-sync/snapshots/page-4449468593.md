Model Creation — 3 of 4: Testing & Publishing (DRAFT)
Last modified: 2026-04-01 (updated by Alex Kearns)

This sub-PRD covers the final phase before a Model goes live: testing the configured field mappings against actual data to validate correctness, and publishing the first version of the model to make it Active.

Key stories: TP1-LC (Trigger Test/Preview), TP2-LC (Select As-Of Date), TP3-LC (Filter by Entity/Row), TP4-LC (View/Resolve Errors), TP5-LC (Publish Model)

Effective Date scenarios covered: A (today/future - standard publish) and C (past date, initial publish - historical backfill). Scenario B (re-publish) deferred to Sub-PRD 4.
