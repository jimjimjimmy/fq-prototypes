# Case Study: Data Studio

**Status:** prototyping  
**Jira:** https://floqast.atlassian.net/jira/polaris/projects/IDEA/ideas/view/11291632?selectedIssue=IDEA-2412

---

## Problem

Lineage Creation workflow prototype within FloQast's Data Studio product. Source-to-target data mapping that enables admins to bring in external datasets, define field mappings to FQ's normalized format, and publish for downstream products.

---

## Goal

Explore and validate two competing AI interaction models for field mapping: directed inline flow vs. conversational chat modal.
