# Case Study: Recs Ag Grid

**Status:** prototyping  
**Jira:** _Not tracked._

---

## Problem

Prototype of FloQast's Reconciliations page rebuilt with real AG Grid (ag-grid-react + ag-grid-community + ag-grid-enterprise), comparing a true grid engine against FlowUI-native table approach.

---

## Goal

Demonstrate recs multicurrency view in AG Grid: Standard/Multi Currency toggle, tree-data row grouping, total footer rows, and custom cell renderers.
