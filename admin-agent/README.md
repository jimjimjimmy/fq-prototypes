# Admin Agent

> An AI agent that helps FloQast admins get their work done.

## What This Is

Admin Agent explores an admin-facing AI copilot for FloQast — an agent that
understands what an admin is trying to do and helps them navigate and complete
it. The first focus is settings & configuration: letting admins describe a change
in plain language instead of digging through nested menus. Prototype-driven
exploration built with FlowUI.
