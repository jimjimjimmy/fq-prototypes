# Case Study: Fdm Rollup

**Status:** prototyping  
**Jira:** https://floqast.atlassian.net/browse/IDEA-2246

---

## Problem

In-app rollup structure editing for FDM (Financial Data Model). Today customers use an Excel round-trip to manage grouping hierarchy. This brings the hierarchy into the app as a first-class object alongside the mapping table.

---

## Goal

Demonstrate a side-by-side rollup structure + mapping table experience with in-app CRUD on hierarchy nodes and account reassignment. Shareable with FDM engineers to shape scope.
