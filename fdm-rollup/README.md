# FDM Rollup

> In-app rollup structure editing for FDM — replace the Excel template round-trip with a side-by-side hierarchy + mapping experience.

## What This Is

A design prototype for IDEA-2246. Today, FDM customers can only edit their financial roll-up hierarchy by downloading an Excel template, editing it offline, and re-uploading — which breaks mapping rules and gives zero live feedback. This prototype explores managing the hierarchy directly in the app, alongside the mapping table, so renames, adds, deletes, and reorders can happen in seconds without breaking rule associations.
